# Fraud Risk Analytics Dashboard — Power BI

## Project Overview

An interactive Power BI dashboard designed to analyze transaction data, identify fraud patterns, and highlight potential areas of risk.

The project demonstrates data cleaning, transformation, DAX calculations, and data visualization using Power BI.

## Project Objectives

- Analyze fraudulent vs. legitimate transactions
- Monitor fraud rate and fraudulent amounts
- Identify fraud trends over time
- Analyze fraud by category, age group, gender, and merchant
- Compare fraudulent and legitimate transaction amounts

## Dashboard Pages

### Page 1 — Fraud Risk Overview

- Total Transactions
- Fraudulent Transactions
- Fraud Rate
- Fraudulent Amount
- Fraud Rate by Month
- Fraud by Category
- Fraud vs. Legitimate Transactions
- Fraud by Age Group

### Page 2 — Fraud Investigation & Risk Analysis

- Average Fraudulent Transaction
- Maximum Fraudulent Transaction
- Fraudulent Customers
- Average Transaction Amount
- Fraud Rate by Merchant
- Fraudulent Transactions by Gender
- Average Transaction Amount: Fraud vs. Legitimate

## Tools

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Transformation
- Data Visualization

## Dataset

The dataset contains transaction information including:

- Customer
- Age Group
- Gender
- Postcode Origin
- Merchant
- Category
- Amount
- Fraud Status
- Month

The data covers four simulated months: May, June, July, and August.
